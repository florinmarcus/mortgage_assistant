# Case stages

Use these stage names exactly in case files, so briefs stay consistent.
A case moves forward one stage at a time. Moving back (for example a declined application)
needs her confirmation and a log entry saying why.

## Mortgage (purchase or remortgage)

| # | Stage | Done when |
|---|---|---|
| 1 | Enquiry | first contact logged |
| 2 | Fact-find | fact-find completed, ID and address checks done |
| 3 | Documents | all required documents received (see `document-checklists.md`) |
| 4 | Recommendation | product chosen, recommendation sent to client |
| 5 | Decision in principle | lender DIP / AIP accepted |
| 6 | Application | full application submitted to lender |
| 7 | Valuation | valuation booked and result received |
| 8 | Underwriting | lender has all it asked for |
| 9 | Offer | mortgage offer issued |
| 10 | Completion | purchase or remortgage completed |
| 11 | Aftercare | case closed; product end date diary note set |

Notes:
- Purchases can wait weeks between Offer and Completion (conveyancing). That's normal; say
  so in the brief rather than flagging it as stuck.
- Remortgages usually skip long conveyancing waits.
- For Aftercare, the useful fact is the product end date: a review is due about 6 months
  before it.

## Protection (life, critical illness, income protection)

| # | Stage | Done when |
|---|---|---|
| 1 | Needs | needs discussed and logged |
| 2 | Quote | quotes sent to client |
| 3 | Application | application submitted |
| 4 | Underwriting | insurer decision received (may need medical evidence) |
| 5 | On risk | policy started |

A protection case is often linked to a mortgage case. Note the link in both case files.

## Stuck cases

A case is "stuck" when nothing has happened for 14 days and it's not waiting on something
expected to be slow (conveyancing, medical reports). Mention stuck cases at the end of a
triage, one line each.
