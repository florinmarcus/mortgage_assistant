# Document checklists

Starting lists only. Lenders differ, and she decides what a case really needs. When she
says a document is not needed for a case, mark it "not needed" in the case file. Don't
remove it from the list.

## Everyone

- Photo ID (passport or driving licence)
- Proof of address (recent utility bill or bank statement)
- Last 3 months bank statements (main account)

## Employed

- Last 3 months payslips
- Latest P60

## Self-employed

- Last 2 years SA302s and tax year overviews, or 2 years accounts
- Business bank statements if the lender asks

## Purchase

- Proof of deposit (savings statements)
- Gifted deposit letter, if a gift is involved
- Memorandum of sale, once an offer on a property is accepted
- Solicitor details

## Remortgage

- Latest mortgage statement
- Redemption figure, when needed

## Protection

- Usually no documents up front. The insurer may ask for medical evidence later.

## Matching attachments to the list

Attachments arrive in `Incoming/` with the date in front of the file name. Match by file
name and the email text (for example "attached my October payslip"). If you can't tell
what a file is, say so and ask her. Never guess that a document has arrived.
