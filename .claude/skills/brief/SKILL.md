# Brief

Speed matters more than detail. She may be on a call.

1. Find the client's case Doc in Drive (`Clients/<Surname> <First name> - ...`).
   If there are several cases, brief the active one and mention the others in one line.
   If you can't find the client, say so at once and ask for the spelling.
2. Read the case Doc: Summary, Documents, top of the Log.
3. Check the client's Gmail label for emails newer than the last log entry.
4. Reply in at most 5 lines:

```
<Name>, <case type> with <lender>. Stage: <stage>, <key date>.
Missing: <documents, or "nothing">.
Next: <next step> by <date>.
Last contact: <date>, <one-word channel>.
<only if relevant: new email not yet logged / case stuck>
```

Rules:
- Facts only from the case Doc and emails. If something is missing, write "not recorded".
- If a new email isn't in the log yet, say so and offer to update the case file after the call.
- Stage names: `docs/workflow/case-stages.md`.
